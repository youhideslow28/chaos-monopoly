# User preferences (hxn)

- Prefers **lean, minimal mechanics** — asked to strip Chaos extras (insurance, counters, non-tile triggers) down to "land on tile → event happens."
- When giving a feature, he wants the **simplest honest version**, not more complexity; he dislikes redundant systems ("loạn quá").
- He confirms scope decisions in short answers; prefers action over clarification once direction is set.
- Values clean/test-verified changes: he expects tests green, build clean, and in-browser verification before handing back.
